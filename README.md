# wood-u-like-site

אתר עצמאי למותג **WOOD U LIKE**. שלב 1: עמוד זמני בעברית, RTL ורספונסיבי.

## פיתוח מקומי

האתר משתמש ב־HTML5, CSS3 ו־JavaScript, ללא תלויות וללא שלב build.

```sh
cd /workspace/wood-u-like-site
python3 -m http.server 8000 --bind 127.0.0.1
```

פתחו את האתר בדפדפן המקומי. אין צורך במפתחות API, שרת יישום או מסד נתונים.

## מבנה

- `index.html` — עמוד הפתיחה, מטא־דאטה, עברית ונגישות בסיסית.
- `assets/css/style.css` — סגנונות ותצוגה רספונסיבית.
- `assets/js/main.js` — מקום להרחבות עתידיות; העמוד פועל גם ללא JavaScript.
- `assets/images/README.md` — הנחיות לחומרי מותג מקוריים.

## GitHub Pages

ב־Settings → Pages בחרו Deploy from a branch, ענף `main`, תיקיית `/ (root)` ושמרו.
כתובת היעד: https://mataniar0.github.io/wood-u-like-site/

## בדיקות לפני העלאה

בדקו טעינת HTML, CSS ו־JavaScript, תצוגת מובייל ודסקטופ, RTL, ניווט מקלדת וללא גלילה אופקית.
בדקו גם הגשה מתחת לנתיב `/wood-u-like-site/` וללא שגיאות בדפדפן.

## שלבים עתידיים

אפשר להוסיף עמודים ותיקיות לקטגוריות, מוצרים, אודות וגרסה באנגלית, ולשמור נכסים משותפים ב־`assets`.
גלריות, התאמה אישית, טופס הזמנה ותשלום יוגדרו במשימות נפרדות. הם אינם ממומשים בשלב זה.
אין כרגע תמונות מוצרים, מחירים, פרטי קשר או לוגו.
