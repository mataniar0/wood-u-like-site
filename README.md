# wood-u-like-site

אתר עצמאי למותג **WOOD U LIKE**. שלב 2: עמוד בית בסגנון Natural Boutique, בעברית, RTL ורספונסיבי.
הגרסה בענף הפיתוח ממתינה לבקרת איכות; האתר הציבורי עדיין מציג את שלב 1.

## פיתוח מקומי

האתר משתמש ב־HTML5, CSS3 ו־JavaScript, ללא תלויות וללא שלב build.

```sh
cd /workspace/wood-u-like-site
python3 -m http.server 8000 --bind 127.0.0.1
```

פתחו את האתר בדפדפן המקומי. אין צורך במפתחות API, שרת יישום או מסד נתונים.

## מבנה

- `index.html` — עמוד הבית, אזורי המותג, עבודות נבחרות ומידע על התאמה אישית.
- `assets/css/style.css` — סגנונות ותצוגה רספונסיבית.
- `assets/js/main.js` — תפריט מובייל נגיש; ניווט חלופי זמין גם ללא JavaScript.
- `assets/images/README.md` — תיעוד חמש התמונות המקוריות וגרסאות WebP רספונסיביות.

## GitHub Pages

ב־Settings → Pages בחרו Deploy from a branch, ענף `main`, תיקיית `/ (root)` ושמרו.
כתובת היעד: https://mataniar0.github.io/wood-u-like-site/
כל נתיבי הנכסים יחסיים כדי לתמוך בנתיב זה. אין דומיין מסחרי.

## בדיקות לפני העלאה

בדקו טעינת HTML, CSS ו־JavaScript, תצוגת מובייל ודסקטופ, RTL, ניווט מקלדת וללא גלילה אופקית.
בדקו גם הגשה מתחת לנתיב `/wood-u-like-site/` וללא שגיאות בדפדפן.

## שלבים עתידיים

אפשר להוסיף עמודים ותיקיות לקטגוריות, מוצרים, אודות וגרסה באנגלית, ולשמור נכסים משותפים ב־`assets`.
גלריות, התאמה אישית, טופס הזמנה ותשלום יוגדרו במשימות נפרדות. הם אינם ממומשים בשלב זה.
קיימות חמש תמונות מקוריות עם גרסאות WebP קטנות וגופני Noto Hebrew מקומיים.
המיתוג מוצג באמצעות Wordmark טיפוגרפי; אין לוגו גרפי רשמי, מחירים או פרטי קשר.
אזור ההתאמה האישית הוא מידע בלבד ואינו מאפשר פנייה או הזמנה.

הפרויקט נפרד מ־ASSEMBLE LAB; אין צורך לשנות את המאגר שלו.

## WUL-002 — עמוד הבית Natural Boutique

עמוד הבית החדש נמצא בענף `feature/natural-boutique-homepage` ומוגש לבדיקת ראש הצוות בלבד.
אין למזג או לפרסם לפני אישור. GitHub Pages נשאר מוגדר לענף `main`.

להגשה תחת נתיב הפרויקט, הריצו מתוך `/workspace`:

```sh
python3 -m http.server 8001 --bind 127.0.0.1 --directory /workspace
```

בדקו פנימית את `/wood-u-like-site/`. כל התמונות והגופנים מקומיים; אין תלות ברשת בזמן טעינת האתר.
גופני Noto Hebrew מופצים ברישיון SIL Open Font License; הרישיונות ב־`assets/fonts/`.
דוח בדיקות, מיפוי תמונות וצילומי מסך זמינים ב־`docs/review/`.
