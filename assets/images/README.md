# תמונות עמוד הבית

רק חמש תמונות שנבחרו מתוך חבילת WOOD_U_LIKE_STAGE2_AGENT_HANDOFF.
המיפוי למקור והחתימות נמצאים ב־`docs/review/photo-sources.csv`.
לכל תמונה גרסת `-small.webp` ברוחב 480px לכל היותר; כולן מוצגות באמצעות `srcset`.

לא הועלו תמונות תינוק, לוח עם שמות משפחה או שלטים עם שמות לקוחות.
צילום הסדנה קוצץ כדי להסיר אריזה עם מספר טלפון; השלטים נשמרו.
קרש המטבח סובב בלבד, ללא שינוי תוכן. אין תמונות סטוק או תמונות גנרטיביות.

לפני החלפה בתמונות הכוללות פרטים מזהים יש לקבל אישור פרסום מפורש.
