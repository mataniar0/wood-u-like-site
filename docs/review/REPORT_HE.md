## המימוש

Header ו־Wordmark טיפוגרפי; Hero ״עץ טבעי. סיפור אישי.״; שלושת ערכי המותג;
ארבע קטגוריות; שלוש עבודות נבחרות; סיפור הסדנה; השראה עם הסחלב וברכת הנרות;

התאמות לאב־הטיפוס: חלופות לתמונות מזהות, הסרת חותמת דקורטיבית כדי להשאיר Wordmark בלבד,

אין טופס, עגלה, סליקה, מחיר, ביקורת או פרטי קשר מומצאים. אזור הפנייה מציין במפורש שאינו פעיל.

## שחזור הבדיקות

נדרשים Node.js, Chromium, Playwright ו־axe-core. אין תלות אלה לאתר עצמו.
בסביבה זו Chromium נמצא ב־`/usr/bin/chromium`; ניתן להגדיר `WUL_CHROMIUM` לנתיב חלופי.

```sh
npm install --prefix /tmp/wul-check --no-save --no-package-lock playwright@1.62.1 axe-core@4.10.3
python3 -m http.server 8001 --bind 127.0.0.1 --directory /workspace
# במסוף נוסף, מתוך שורש המאגר:
NODE_PATH=/tmp/wul-check/node_modules node tools/check-homepage.cjs
```

ניתן להגדיר `WUL_BASE_URL` לכתובת בדיקה אחרת. הרצת הבדיקות מעדכנת תוצאות וצילומי מסך בלבד.
