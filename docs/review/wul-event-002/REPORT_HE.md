## עבודה שהושלמה ללא הנכסים

- ALT, כותרות, תיאורים ו־CTA בכרטיס ובגלריה מחוברים למנוע event.* הקיים ב־HE/EN. הוסרו span-ים כפולים שתלויים בהסתרה דרך CSS. ALT נשאר תיאור כללי המבוסס על האפיון; יש לאמת אותו מול הקבצים בפועל לאחר צירופם.

## השלמה נדרשת מהחבילה המאושרת

| קובץ ב־assets/images/ | מידות לפי האפיון |
|---|---|
| wedding-magnets-original.webp | 1200×1600 |
| wedding-magnets-original-small.webp | 600×800 |
| wedding-magnets-styled-concept.webp | 1122×1402 |
| wedding-magnets-styled-concept-small.webp | 600×750 |

יש לצרף את ZIP המקור או את ארבעת ה־WebP המאושרים. לאחר קבלתם: לבדוק את התצלומים עצמם, להעתיק bytes מאושרים ללא שינוי חריטה, לרשום SHA-256 ומקור, להוסיף qa/assets/wedding-magnets.json עם ארבע החתימות בפועל ולעדכן approved_asset_files בחוזה runtime. אין להמציא hashes, לעדכן manifest לאישור קובץ שלא נפתח או להכניס תמונה חלופית. קובצי המקור ZIP נשארים מחוץ ל־Git.

לאחר מכן נדרשות בדיקות HE/EN × 390/1440, המקור וגרסת הקונספט, כל קישורי הניווט בעמודים הקיימים, נגישות וקישורים, תמונות בגודל קטן/גדול, שימור האתר ו־CI נדרש, וצילומי מסך נגישים לביקורת ChatGPT. סוויטת wedding-magnets נרשמה ב־event shard; full כולל כעת 24 suites. אין שינוי/החלשה של ה־selectors או הספים הקיימים.
