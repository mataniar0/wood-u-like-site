# WUL-004 — דוח פיתוח ובקרת איכות

Refs #5. בסיס: `main` במזהה `93b9cadfbc204b24939627abb718ba08a51bbc9b`; ענף `feature/wul-004-inquiry`. לא בוצעו Merge, Deploy, מחיקת ענף או שינוי במאגר ASSEMBL LAB.

## מה נבנה

עמוד `inquiry/` בעיצוב Natural Boutique, עם כותרת **בקשת הזמנה / Order inquiry**, שלוש תחנות התהליך ו־RTL/LTR מלא. נוסף CTA ברור בדף הבית, בלי להסיר את כפתורי המידע הקיימים. שלושת כרטיסי המוצרים מפנים למזהי מוצר מותרים ובוחרים מראש את המוצר בשפה הפעילה.

הטופס כולל מוצר, שם, אמצעי קשר אחד וכמות; חריטה/הקדשה, מידות במ״מ לפי מוצר, תיאור רעיון אחר, הערות והעדפת קבלה הם רשות. רעיון אישי מוצג כ־**בתכנון / לשיחת היתכנות**. אין מחיר אוטומטי, הבטחת ייצור, זמן אספקה, העלאת קבצים או אינטגרציית תשלום. Grow מוזכר רק כקישור שבעל העסק עשוי לשלוח ידנית לאחר אישור.

מנגנון השליחה כולל אימות מתורגם, שגיאות ליד השדות, `aria-live`, פוקוס, honeypot, נעילת טופס בזמן המתנה, timeout של 12 שניות, acknowledgment אמיתי כתנאי להצלחה ושמירת טיוטה בעמוד בכשל. טיוטה שאושרה אינה נשלחת שוב ללא שינוי ממשי בפרטים. מצבי timeout/רשת מסבירים שקבלת הבקשה אינה ידועה ושצריך לבדוק לפני ניסיון נוסף.

## מצב ההפעלה הציבורית — חסום בכוונה

`inquiry/contact-config.js` מכיל endpoint ופרטי קשר ריקים, ודגלי אישור כבויים. השליחה נשארת מושבתת גם ב־submit מתוכנת ובמצב ללא JavaScript. WhatsApp ואימייל אינם מוצגים ללא פרטים ייעודיים מאושרים.

חסרים **מזהה Formspree ייעודי ל־WOOD U LIKE** ו־**נוסח פרטיות מאושר בעברית ובאנגלית**. אלה חסמי הפעלה ציבורית, ולא חסמים למסירת PR של התשתית לפי Issue #5. הוראות למנהל האתר נמצאות ב־[inquiry/README.md](../../../inquiry/README.md). לא הומצא נוסח משפטי ולא הופעל שירות חי.

אין טיוטת לקוח ב־localStorage/sessionStorage, בכתובת העמוד, בלוגים או בדוחות. רק העדפת השפה נשמרת. בפתיחה יזומה של ערוץ חיצוני מאושר בלבד, ההודעה נכללת ב־URI של האפליקציה כמתחייב מהאפיון; הקישור הזמני מוסר לאחר הפתיחה. צילומי מצב ממולא מסתירים את השדות; תצוגת ברירת המחדל מצולמת ללא נתונים.

## שחזור

פקודות הבדיקה והתקנת תלויות QA בלבד נמצאות ב־[inquiry/README.md](../../../inquiry/README.md). אין build או תלויות runtime לאתר.

לשחזור ההשוואה למקור, כשהשרת המקומי על פורט 8002 פעיל:

```sh
python3 tools/prepare-reference-inquiry.py
# Use the WUL_REFERENCE_URL printed by the preparation command:
WUL_REFERENCE_URL=<printed-local-reference-url> NODE_PATH=/tmp/wul-check/node_modules node tools/check-reference-inquiry.cjs
```

ההכנה מורידה קבצים מגרסה מוצמדת בקריאה בלבד דרך GitHub HTTPS הקיים, יוצרת תיקייה זמנית חדשה מחוץ ל־checkout, ואינה מורידה או מפעילה הגדרת קשר חיה. גם ההרצה הזו חוסמת תעבורה חיצונית ויוצרת acknowledgment מדומה בלבד.

## ספירת תיקונים ומגבלות

**4 מחזורי תיקון:** (1) יישור שדות באותה שורה בדסקטופ; (2) שימור הודעת הצלחה וחסימת כפילות מול אירוע change מאוחר בעת מעבר פוקוס; (3) תיקון ניהול השעון המדומה בבדיקת timeout; (4) תיקון צילומי QA — הסתרת שדות גלויים בלבד, צילום מהחלק העליון ורענון לפני צילום ברירת מחדל. שני הראשונים תיקוני מימוש, שני האחרונים תיקוני כלי בדיקה/ראיות. הכשלים הראשוניים נחקרו ולא הוסתרו; ההרצות הסופיות המלאות עברו.

הבדיקות משתמשות ב־Chromium ובשירות מדומה בלבד. לא נבדקו שירות Formspree חי, אפליקציות מייל/WhatsApp חיצוניות, דפדפנים אחרים או פריסת GitHub Pages. היעדר אישור לאחר timeout/רשת אינו הוכחה שהשירות לא קיבל את הבקשה. לא נטען ציון QA עצמי; סף 90/100 ואישור מיזוג הם של ראש הצוות. הענף נשאר פתוח לביקורת ולא נמחק.
