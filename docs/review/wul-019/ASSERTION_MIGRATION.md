# התאמת הרגרסיה למבנה החדש

| check-collections | 4 קישורי בית טבעיים, 0 כרטיסי מוצר בבית, ארבעה עמודי קולקציה, 3+2+1+1 מוצרים, SEO, תמונות וחתימות, HE/EN, חמשת הרוחבים, no-JS ופיקסלים ב־PNG, E2E לכל מוצר |

בדיקות משלימות: `check-fragment-navigation` לכל 13 העוגנים, ו־`check-collection-accessibility` ל־skip link, תפריט עם Space/Tab/Escape, גודל מטרות, החלפת שפת SEO, reduced motion, בית סופי ב־320px והעדפת EN שנשמרה בפועל כאשר JavaScript מושבת.

כשל harness ראשון נשמר ולא הוסתר: `check-homepage` ניסה לחפש הורה `.product-card` לקישור legacy שאינו כרטיס. התיקון מגביל את בדיקת הקטלוג לכרטיסים ומשאיר בדיקה נפרדת וחזקה לכל יעד legacy. פירוט וראיות ב־[CORRECTION_CYCLES.json](CORRECTION_CYCLES.json).

מחזור QA שני, בעקבות סקירת הקוד ולא בעקבות FAIL בהרצה: נוספה ב־`check-collection-contract` השוואת כל מפתחות התרגום המקוריים לבסיס (מלבד nav.favorites המורשה), ובדיקות ALT מפורשות למזוז/שוורץ/מרדה. בשילוב בדיקות הדפדפן שמאמתות ALT בפועל מול המילון, נשמרים גם הערכים הליטרליים המאושרים ולא רק שמות המפתחות. שער השימור הורץ מחדש ועבר; לא השתנה קוד אתר. ראיות ב־PRESERVATION.json וב־contract-run-2.log.
