# תנאים וחסמים פתוחים

- גישה ציבורית לשני אתרי GitHub Pages אינה אפשרית במדיניות הרשת הנוכחית; לא בוצעו ניסיונות חוזרים ולא אומת SHA מוגש.
- תנאי עיבוד והעברה לחו״ל/DPA/SCCs טרם הוכרעו. תשובת Formspree היא ראיה שמסר הבעלים, לא הוכחת הסדר מחייב או ביצוע מחיקה.
- אישור בעלים לנוסח ולגרסה המדויקים עדיין נדרש; כל ארבע המדיניות טיוטות noindex. אין אפשרות לראות הוספת קישור כאישור פרסום.
- 2FA ומחיקה תפעולית מקצה לקצה לא אומתו מחדש; לא שונו חשבונות ולא נמחק מידע.
- AL pre-push מפעיל tests/site_smoke.py עם מילוי ו־submit מדומים. לפי AGENTS.md נדרשת הבדיקה לפני push; לפי המשימה היא אסורה. לא הורץ ולא נעקף hook. נדרש מסלול מאושר שאינו מגיש טופס.
- GitHub API אינו מותר בסביבה. Draft PR לא נפתח. גם CI שמופעל אוטומטית חייב להתאים לאיסור שליחת fixtures; לא הוחלש CI לצורך פתיחת PR.
- צילומים נשמרו מקומית וחתימותיהם באינדקס; אין כאן יכולת לצרף קבצים לצ׳אט, ואין טענה שהם זמינים לקורא החיצוני. סיכומי QA טקסטואליים committed עם הקוד.
- בשילוב עתידי מאושר של WUL-EVENT-004 יש להפיק מחדש את עמוד האירועים ואת runtime hash המשולב. בדיקת snapshot שמרה את הגלריה והמשפחות; אף ענף קיים לא נכתב.

אין כשל מקומי פתוח בבדיקות המותרות. החסמים אינם אישור לעקוף pre-push, להפעיל דגלים, לשלוח פניות או לבצע Merge/Deploy. ChatGPT יכריע בשלב הבא.
