# בדיקות קבלה לעמודי המוצר — WUL-018

מקור התוצאות הוא [results.json](results.json). מצב `PASS` נכתב רק לאחר סיום כל המטריצה; תוצאה עם `RUNNING` אינה דוח קבלה מלא.

## הרצה

שרת הבדיקה מציב את המאגר מתחת ל־`/wood-u-like-site/`, כמו GitHub Pages. אין בדיקה שמניחה שהאתר נמצא בשורש הדומיין.

```sh
python3 -m http.server 8012 --bind 127.0.0.1 --directory /workspace
WUL_BASE_URL=http://127.0.0.1:8012/wood-u-like-site/ NODE_PATH=/tmp/wul-check/node_modules node tools/check-product-pages.cjs
```

הרצת הדוגמה בשלב A: אותו כלי עם `WUL_PRODUCT_SAMPLE=1`. היא בודקת את `family-sign` ב־HE/EN וברוחבי 320/1440, ושומרת תוצאות וצילומים תחת [stage-a](stage-a/results.json).

הכלי מקבל גם `WUL_REVIEW_DIR`, `WUL_BASE_COMMIT` ו־`WUL_CHROMIUM`. בסיס העבודה במשימה זו הוא `7557010`; יש לשמור בסיס זה בבדיקה חוזרת של אותו PR.

## היקף הבדיקה

- 70 תרחישי עמודי מוצר: שבעה מוצרים × שתי שפות × רוחבי 320, 390, 768, 1024 ו־1440. לכל תרחיש נבדקים מסלול 200, H1, מטא ו־OG, canonical, תרגום טקסט/ALT/ARIA, תמונות מאושרות, קישורים תחת קידומת Pages, overflow, צילום ו־axe. כל מוצר בכל שפה נבדק גם במסלול ניווט מלא ברוחב 390: שיתוף ישיר, רענון, חזרה לקולקציה, מוצר, טופס, back/forward וחזרה הביתה.
- עשרה תרחישי דף הבית: ארבע קולקציות פיזיות, שבעה כרטיסים פעם אחת כל אחד, legacy IDs, קישורי מוצר/טופס, גובה תמונה קומפקטי, הסרת תגיות חוזרות, תרגומים, תמונות, קישורים, צילום, נגישות והיעדר חפיפות/overflow.
- 15 תרחישי no-JS בעברית הסטטית: כל שבעת המוצרים ב־390 וב־1440, ועוד השעון ב־320. נבדקים צילום ראשי מצויר, טקסט סטטי, Breadcrumb, קישורי HTML ובוררי שפה מושבתים. לשעון נבדקים בדיוק שלושה קישורים מקוריים לקבצים המאושרים, התאמת בתים ופקדים מושבתים. בנוסף נבדק ניווט HTML מהבית דרך כל שבעת המוצרים לטופס ובחזרה, ללא JavaScript.
- 14 תרחישי metadata עם POST מדומה: שבעה מוצרים × HE/EN, כניסה למוצר עם query בטוח ושדות זרים, מעבר לטופס, preselection, מזהים ושמות קנוניים, brand/source_site, source_page ללא query, שיוך קמפיין ו־storage נקי.
- גלריית השעון נבדקת בכל עשרת תרחישי השעון: שלוש תמונות מאושרות ובסדרן, next/prev, wrapping, Home/End, כיווני מקשים RTL/LTR, פוקוס גלוי, הכרזה ומונה, שמירת השקופית בהחלפת שפה ו־reduced motion. צילומי שלוש התמונות נשמרים ב־HE/EN ב־390 וב־1440.

## הוכחת צילום וגבולות הבדיקה

הכלי גולל אל התמונות עצמן וממתין ל־`img.decode()`. הוא קורא את קובץ ה־PNG שנשמר בפועל, דוגם את 60% המרכזיים של אזור התמונה ומחייב יותר מ־100 צבעים שונים ופחות מ־95% לצבע הדומיננטי. בדיקת ביקורת של מלבן אחיד מוכיחה שהבדיקה דוחה placeholder. הפענוח נעשה בעמוד מבודד המותר ב־JS גם כאשר האתר עצמו נבדק ללא JS; הוא אינו טוען אתר ואינו מבצע בקשת רשת.

כל קובצי ה־WebP נבדקים מול SHA-256 של בסיס העבודה. גם `inquiry/contact-config.js`, קוד הטופס וקוד השיוך חייבים להישאר זהים לבסיס. שלוש הרשאות ההפעלה הציבורית נשארות `false`. בתרחישי השליחה מוחזר fixture של הגדרות רק בדפדפן הבדיקה, וכל POST נענה במיירט מקומי לפני הרשת. כל בקשה חיצונית אחרת וכל שליחה לא צפויה נחסמות ומכשילות את הכלי.

סביבה: Node.js 24.19.0, Playwright 1.62.1, axe-core 4.10.3 ו־Chromium 154.0.8037.57. לא בוצעו Firefox/Safari, בדיקת קורא מסך אנושית או בדיקת האתר החי. אין מכאן אישור Merge/Deploy או הפעלת שליחה ציבורית.
