# נכסי WUL-020

מוצר אחד: שלטי חדר אליפטיים / Personalized Oval Room Signs (`oval-room-signs`).
התצלום מציג שלוש דוגמאות כיתוב; אין הבטחה לערכת שלושה פריטים.

הקובץ שנזכר בבקשה לא נמצא בסביבת העבודה או ב־main. נעשה שימוש בתצלום המאושר הקיים `workshop.webp`, התואם במדויק לשלושת שלטי החדר, וממופה ל־R1-09 בחבילת המקור. נוצרו עותקי WebP ייעודיים למוצר, זהים לחלוטין בבתים לגרסאות המאושרות; תמונת הסיפור המקורית נשארה ללא שינוי. לא בוצע שינוי גרפי, יצירת תוכן או קידוד מחדש.

PHOTO_MANIFEST.json מתעד מקור, עיבוד קודם, מידות וחתימות SHA-256. ה־ZIP הוא חבילת מסירה חדשה בנתיב שנדרש, ואינו מוצג כחבילת מקור שהתקבלה. יש לאמת מול בעל המשימה אם התכוון לתצלום אחר.
